# Cape Town: The Chosen 🌿

2D-экшен-платформер про Элахима, который защищает гору Тейбл-Маунтин от кибер-смог дронов.

## Запуск (режим разработчика)

```bash
npm install   # зависимости ставятся без флагов — конфликты peer-deps исправлены
npm run dev   # http://localhost:3000
```

Другие команды:

| Команда          | Что делает                                  |
|------------------|---------------------------------------------|
| `npm run dev`    | Dev-сервер Vite (тестовая среда включена)   |
| `npm run build`  | Production-сборка в `dist/`                 |
| `npm run preview`| Локальный предпросмотр production-сборки    |
| `npm run lint`   | Проверка типов TypeScript (`tsc --noEmit`)  |
| `npm run clean`  | Удалить артефакты сборки                    |

## Тестовая среда разработчика

Основной движок игры — Canvas 2D (`src/App.tsx`). Дополнительно есть стенд
на Phaser для проверки тайловой сетки (`src/GameTest.tsx`).

Как попасть в тестовый стенд:

1. **Режим разработки** (`npm run dev`): на титульном экране и в HUD появляется
   кнопка «Launch Phaser 3 Tile Seam Test» (колба ⚗️).
2. **В production-сборке** кнопки скрыты; включить их можно параметром URL:
   `?test=1` или `#test`.

Логика флага — в `src/dev.ts` (`DEV_MODE`). Сам Phaser грузится лениво
(`React.lazy`), поэтому в обычном бандле его кода нет.

## Структура проекта

```
src/
  App.tsx        # основной движок игры (Canvas 2D, ~2400 строк): уровни, босс, кристаллы, звук, тач-управление
  GameTest.tsx   # тестовая Phaser-сцена (dev-only, ленивая загрузка)
  dev.ts         # флаг DEV_MODE
  main.tsx       # точка входа
  index.css      # Tailwind v4
public/
  *.png                       # спрайты Элахима, врагов, фон и тайлсет
  assets/GandalfHardcore ...  # сторонний тайловый пак (используются несколько файлов)
  assets/GandalfHardcore .../_unused/   # неиспользуемые файлы пака — перемещены сюда, можно удалить после проверки
  standalone.html             # автономная версия игры (без React/Vite)
.assets_backup/               # локальный кэш сгенерированных ассетов (в .gitignore)
```

## Что убрали при чистке репозитория

- неиспользуемые зависимости: `@google/genai`, `express`, `@types/express`, `dotenv`, `motion`, `autoprefixer`, `tsx`;
- дублирующийся lock-файл `bun.lock` (оставлен только `package-lock.json`);
- `.env.example` (код не читает переменные окружения);
- кэш AI Studio (`.aistudio/`, `public/assets/aistudio/` — пиксельные дубликаты спрайтов);
- 76 неиспользуемых файлов тайлового пака перемещены в `_unused/` внутри `public/assets/`
  (не удалены — удалите сами, когда убедитесь, что игра работает).
